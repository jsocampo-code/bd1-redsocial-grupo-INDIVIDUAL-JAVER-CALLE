# Red Social Pascualina - Modelo Conceptual de Base de Datos

## Información del Proyecto
* **Asignatura:** Bases de Datos I
* **Institución:** Institución Universitaria Pascual Bravo

## Integrantes
* **Javer Stiven Calle Ocampo** *(Trabajo Individual)*

## Descripción del Caso

La Red Social Pascualina es un proyecto creado para conectar a los estudiantes de la institución fuera de las aulas, facilitando que puedan conocerse, crear grupos de estudio, organizar eventos y ayudarse mutuamente en sus materias. Para lograrlo, diseñamos una base de datos organizada y fácil de entender que guarda la información de los usuarios, sus publicaciones, sus grupos y las habilidades que manejan, asegurando que el sistema funcione de forma rápida y sin enredos a medida que más estudiantes se unan a la plataforma.
